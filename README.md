# Caddy

Parametric model of a rolling shelf cart, built with [Cadova](https://github.com/tomasf/Cadova).

## Build

```sh
task run     # generates caddy.3mf
```

Open `caddy.3mf` in [CadovaViewer](https://github.com/tomasf/CadovaViewer) for live reload.
